Referral protection

Delivery + payment confirm the reward.

A referral code alone never earns points. The friend must join with the code before ordering, their first qualifying order must be at least $25 after discount, be marked Delivered, and have payment confirmed as Received in Orders & history. The database issues each referral bonus only once, normalizes Lebanese phone formats, blocks same-phone referrals, and does not allow retroactive referral credit.
